# BERKAS_A_-1-_Dataset_KabutAsap

## 1. Deskripsi Proyek

Proyek ini berisi pengumpulan dan pengolahan video yang mendokumentasikan kondisi kabut asap akibat kebakaran hutan dan lahan (karhutla). Video dikumpulkan dari berbagai sumber, kemudian dipilih, diedit, dan diambil beberapa frame citranya sebagai bahan dokumentasi.

## 2. Tujuan

1. Mengumpulkan minimal 30 video tentang kondisi kabut asap.
2. Mendokumentasikan kondisi kabut asap melalui video.
3. Mengolah video menjadi klip berdurasi 5–15 detik.
4. Melakukan ekstraksi frame citra dari video.
5. Menyimpan informasi sumber asli setiap video.

## 3. Informasi Dataset

- Jumlah video: 20 video
- Format video: MP4
- Durasi setiap video: 5–15 detik
- Jumlah frame: 20
- Tema: Dokumentasi kabut asap akibat karhutla.
